Ollama Provider

Cost Tier: Free (hardware only) · Rate Limit: GPU-dependent · MCP Support: ✅ Native

Supported Models

  • LLaMA 3.1 — Meta's open instruction-tuned model (8B, 70B)
  • Mistral — Efficient open model
  • Qwen 2.5 — Alibaba's multilingual model
  • Phi-3 — Microsoft's efficient small model
  • Any GGUF-format model — Custom model support

How A3M Router Routes to Ollama

Ollama provides completely free, local inference. A3M Router routes to Ollama for:

  • Maximum privacy (no data leaves your infrastructure)
  • Zero API costs for high-volume simple tasks
  • Development and testing without API key requirements

Configuration

# Install Ollama, then pull models:
# ollama pull llama3.1
# ollama pull mistral

# A3M Router connects to local Ollama at http://localhost:11434
# No API key required — zero cost for inference

Requirements

GPU recommended for reasonable inference speed. CPU-only works for small models (7B params) but is significantly slower.
