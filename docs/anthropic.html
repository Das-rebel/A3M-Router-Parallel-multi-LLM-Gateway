How A3M Router Routes to Anthropic

Anthropic models are preferred for:

  • Complex coding and debugging tasks (Claude 3.5 Sonnet excels here)
  • Safe, helpful assistant interactions
  • Document analysis with large context windows (200K for Claude 3.5)
